# 允许通过 WAN 网卡访问管理 UI

Gateway apply 生成的 `gateway_kit` input 链现允许配置的 WAN 网卡访问 UI 端口；LAN 与 loopback 访问保持可用，其它接口仍被该 UI 端口规则拒绝。HTTP API 使用管理员用户名/密码登录和 HttpOnly 会话 Cookie；未修改监听地址。

UI 前端提供用户名/密码登录、首次登录强制修改密码和账号安全页。管理界面仍使用 HTTP，公网访问应经过 HTTPS 反向代理或 VPN，以免凭据和会话在链路上明文传输。

本次仅修改项目代码与文档，没有在生产网关应用规则。实际外网可达性还取决于上游路由器、安全组和宿主机其它防火墙规则。
